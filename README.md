# AstraNotes

A secure, modular, local-first note-taking application built in Python.

**Course:** CSEN 296B-2 AI-Driven Software Development, Santa Clara University, Spring 2026
**Student:** Atishay Jain

## Setup

```bash
python -m venv venv
source venv/bin/activate
pip install -e ".[dev]"
```

## Run Tests

```bash
pytest
```

## Run Application

```bash
python -m astranotes
```
